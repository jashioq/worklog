# worklog

Personal work log, kept locally and organized by Claude Code. Never pushed; git is only for history and rollback.

## Files
- `daily/YYYY/YYYY-MM-DD.md`: what I did each day. Past days are append-only; corrections go in appendices.
- `open.md`: everything still open (discussions, todos, deadlines). Done items are removed.
- `glossary.md`: one line per `[[link]]`, saying what it means.
- `FORMAT.md`: the rules and templates both skills follow.

## Daily use
- **Morning:** `/brief` gives a read-only summary of what needs attention today.
- **EOD:** `/log <rough notes>`. It asks only when unsure, shows one review of all proposed changes, writes them once I approve, and commits.
